# EduForge

Arbeitsblätter, Klassenarbeiten und Unterrichtsplanung für die Grundschule –
lokal auf deinem Computer. Keine Cloud, keine Anmeldung.

## Herunterladen

**[Neueste Version herunterladen](https://github.com/Rn11/eduforge-download/releases/latest)** –
dort unter „Assets“:

- **Windows:** `EduForge-Setup-<Version>.exe`
  Installation ohne Administratorrechte. Eine vorhandene Version wird
  aktualisiert – Arbeitsblätter, Planungen und Einstellungen bleiben
  erhalten. Windows zeigt eventuell eine SmartScreen-Warnung, weil das
  Programm (noch) nicht signiert ist: „Weitere Informationen“ → „Trotzdem
  ausführen“.
- **Linux:** `EduForge-<Version>-linux-x86_64.tar.gz`
  (Ubuntu 22.04 und neuer, Linux Mint, Debian 12, Fedora …). Entpacken und
  `./installieren.sh` ausführen – ohne Administratorrechte, mit Eintrag im
  Anwendungsmenü.
- `SHA256SUMS.txt`: Prüfsummen aller Dateien.

Was sich in jeder Version geändert hat, steht beim jeweiligen Release.

## Datenschutz

EduForge arbeitet lokal. Ins Netz geht es nur mit deiner Zustimmung: für die
Update-Prüfung (liest die Datei `version.json` dieses Repos) und wenn du eine
Rückmeldung sendest. Details:
[Datenschutzerklärung](https://xwing.dev/eduforge/datenschutz.html).

Dieses Repository enthält nur die fertigen Programme, nicht den Quellcode.
